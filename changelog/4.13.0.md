# 4.13.0

发布日期：2026-11-28

## Changes

- public: 清理无引用的静态资源，保留微信模块依赖的二维码脚本
- frontend: 升级 Vue.js 运行时至 v2.7.16
- db: 优化全新安装的数据库索引
- admin: 补充后台 CSRF Token 和 Element UI 上传接入示例

## Fixes

- tests: 隔离测试缓存，避免污染运行时缓存，并为登录页站点名称提供缺省值
- downloader: 加固下载中心的 SSRF 防护和重定向校验
- cron: 限制可执行的计划任务脚本
- upload: 禁止上传 SVG 以防止存储型 XSS
- admin: 修复操作日志详情弹窗的存储型 XSS
- admin: 增加按账号锁定的登录防爆破机制和受信代理 IP 校验
- admin: 对操作日志响应脱敏，并规范参数化查询和 LIKE 转义
- security: 加固域名解析后的连接目标校验、对象存储直传策略和签名 URL 脱敏
- upload: 修复阿里云私有链接签名参数和缓存隔离
- admin: 为后台会话写请求增加 CSRF 校验，校验失败时提示刷新页面
- common: 将附件管理和计划任务的相关写接口限制为 POST
