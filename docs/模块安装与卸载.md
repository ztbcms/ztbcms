# 模块安装与卸载

## 模块安装流程

在后台通过 **模块管理 > 本地模块** 进行安装操作。

### 安装步骤

系统安装模块时按以下顺序执行（参考 `app\admin\libs\module\ModuleInstaller`）：

1. **目录权限检查** — 检查模块目录是否可读
2. **读取模块配置** — 加载 `Config.inc.php` 获取模块信息
3. **CMS 版本校验** — 比较 `adaptation` 字段与当前 CMS 版本
4. **依赖模块检查** — 检查 `depend` 中列出的模块是否已安装
5. **重复安装检查** — 防止模块被重复安装
6. **写入模块记录** — 向 `module` 数据库表插入模块信息
7. **执行安装 SQL** — 运行 `install/{ModuleName}.sql` 建表脚本
8. **安装后台菜单** — 读取 `install/Menu.php` 注册菜单和权限节点
9. **复制静态资源** — 将 `install/extra/` 目录的文件复制到 `public/statics/extra/{模块名}/`

> 如果安装过程中 SQL 执行或菜单注册失败，系统会自动回滚（删除 module 表中的记录）。

### 安装前提

- 模块目录已放置到 `tp6/app/` 下
- `Config.inc.php` 文件存在且配置正确
- CMS 版本满足 `adaptation` 要求
- 所有依赖模块已安装

---

## 模块卸载流程

在后台通过 **模块管理 > 已安装模块** 进行卸载操作。

### 卸载步骤

系统卸载模块时按以下顺序执行（参考 `app\admin\libs\module\ModuleUninstaller`）：

1. **目录权限检查**
2. **验证模块已安装** — 检查 `install_time` 是否存在
3. **删除模块记录** — 从 `module` 数据库表中删除
4. **删除菜单和权限** — 清除 `menu` 表和 `access` 表中该模块的所有记录
5. **执行卸载 SQL** — 运行 `uninstall/{ModuleName}.sql` 删表脚本
6. **删除静态资源** — 清除 `public/statics/extra/{模块名}/` 目录

### 注意事项

- 卸载**不会删除**模块的源代码目录（`tp6/app/{模块名}/`），仅清理数据库和菜单
- 卸载后可以重新安装
- 系统模块（`admin`、`common`、`install`）不可卸载
- 卸载前请确认没有其他模块依赖当前模块
