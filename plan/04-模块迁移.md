# 阶段 4: 模块迁移 — 6 个应用模块逐个适配

> **目标**: 将 tp6 的 6 个应用模块（common/admin/api/home/install/demo）逐个适配到 TP8。
> **前置**: 阶段 2-3 完成，核心层和配置已适配。
> **策略**: 按依赖顺序迁移，先 common，再 admin/api，最后 home/install/demo。

---

## 4.1 模块依赖关系

```
common ──┬── admin (依赖 common 的中间件、服务、模型、taglib)
         ├── api   (依赖 common 的中间件、JWT 服务)
         ├── home  (几乎无依赖)
         ├── install (依赖 common 的服务)
         └── demo  (独立)
```

### 4.2.2 关键文件适配

#### `taglib/Template.php` + `taglib/Ztbcms.php` — 已验证为死代码 ✅

**验证结论**: 经全项目搜索，没有任何模板文件使用 `{ztbcms:include}` 自定义标签。整个 taglib 目录是死代码。

**操作**: 直接移除以下 3 项：
```bash
# 1. 删除 taglib 目录
rm -rf tp8/app/common/taglib/

# 2. 移除 config/view.php 中的 taglib_pre_load 配置
# 删除: 'taglib_pre_load' => 'app\common\taglib\Ztbcms'
```

**无需重构、无需适配，直接删除即可。**

#### `middleware/AdminAuth.php`

**框架 API 使用**:
- `think\facade\Config::get()`
- `think\facade\View::assign()` / `fetch()`
- `app()` 容器助手
- `session()` 助手
- `cache()` 助手

**适配要点**: 大部分 Facade 和助手函数在 TP8 中不变，逐个验证即可。

#### `middleware/Cors.php`

**适配要点**: 低风险，主要使用 `think\facade\Request` 和 `think\Response`。

#### `service/BaseService.php`

**适配要点**: 检查是否使用 ORM API，ORM 从 `^2.0` 升级到 `^3.0`。

#### `model/ConfigModel.php` / `UserModel.php`

**适配要点**:
- 模型基类 `think\Model` 在 TP8 中命名空间不变
- `think-orm ^3.0` 可能有 Breaking Change
- 检查使用的查询构建器方法是否废弃

### 4.2.3 操作步骤

```bash
# 1. 复制整个 common 目录
cp -r tp6/app/common tp8/app/common

# 2. 移除死代码 taglib
rm -rf tp8/app/common/taglib/

# 3. 逐文件修复编译错误
cd tp8
php -l app/common/middleware/AdminAuth.php
# ...

# 4. 运行自动加载
composer dump-autoload
```

### 4.3.2 适配要点

| 组件 | 关注点 |
|------|--------|
| 控制器 | 均继承 `app\common\controller\AdminController` 或 `app\BaseController`，通过基类统一适配 |
| 模型 | `think\Model` 基类方法签名是否变更 |
| 服务 | 可能使用 `Db` facade 或 ORM 查询构建器 |
| 验证器 | `think\Validate` 已独立为 `think-validate ^3.0`，命名空间可能变更 |
| 视图 | 模板文件中不使用自定义 taglib（已验证为死代码） |
| Config.inc.php | 自定义模块元数据格式，不依赖框架 |

### 4.3.3 操作步骤

```bash
cp -r tp6/app/admin tp8/app/admin

# 检查所有 PHP 文件语法
find tp8/app/admin -name "*.php" -exec php -l {} \;

# 检查 Validate 类引用
grep -rn "think\\\\Validate" tp8/app/admin/ --include="*.php"
grep -rn "use think\\\\Validate" tp8/app/admin/ --include="*.php"
```

## 4.8 ORM 查询兼容性检查

TP6 的 `think-orm ^2.0` 到 TP8 的 `think-orm ^3.0` 可能有以下变更：

```bash
# 扫描所有 ORM 使用
grep -rn "Db::" tp8/app/ --include="*.php" | head -50
grep -rn "->where(" tp8/app/ --include="*.php" | head -50
grep -rn "->join(" tp8/app/ --include="*.php" | head -50
grep -rn "think\\\\db\\" tp8/app/ --include="*.php"
```

**常见 ORM Breaking Change**:
- `Db::table()` → `Db::table()` (通常不变)
- `whereRaw()` / `whereOrRaw()` 方法是否仍存在
- 软删除、模型事件等 API
- `DataNotFoundException` / `ModelNotFoundException` 命名空间
