# ZTBCMS ThinkPHP 6 → ThinkPHP 8 升级总计划

> **分支**: `tp8`
> **策略**: 保留 `tp6/` 不动，新建 `tp8/` 目录，独立演进
> **日期**: 2026-07-29

---

## 一、项目背景

当前 ztbcms 项目以 `tp6/` 作为应用根目录，基于 ThinkPHP **6.1.5**（PHP `>=7.4 <8.0 || >=8.3 <8.4`）。ThinkPHP 8 要求 **PHP >= 8.0**，核心包发生重大变更：

| 维度 | ThinkPHP 6 | ThinkPHP 8 |
|------|-----------|------------|
| PHP 版本 | >= 7.2.5 | **>= 8.0** |
| ORM | `think-orm ^2.0` | **`think-orm ^3.0\|^4.0`** |
| 框架核心 | `framework ^6.0` | **`framework ^8.0`** |
| 验证器 | 内置于 framework | **独立 `think-validate ^3.0`** |
| 容器 | 内置于 framework | **独立 `think-container ^3.0`** |
| helper | `think-helper ^1.0` | **`think-helper ^3.1`** |
| 多应用 | `think-multi-app ^1.0` | **`^1.1`**（v1.1.1 已支持 `^6.0\|^8.0`） |
| 视图 | `think-view ^1.0` | 需确认 TP8 版本 |
| 队列 | `think-queue ^3.0` | 需确认 TP8 版本 |
| 调试工具 | `think-trace ^1.0` | **`think-trace ^2.0`** |
| 调试 Dump | `symfony/var-dumper` | **`think-dumper ^1.0`** |

```

│   ├── vendor/   # TP8 依赖
│   ├── think     # CLI 入口
│   ├── composer.json
│   ├── .env.example
│   └── ...
├── plan/         # 开发计划（本目录）
├── docs/         # TP6 文档（保持不动）
├── docs_tp8/     # TP8 文档（升级过程中产出）
└── Makefile      # 需新增 tp8 相关 target
```

### 阶段 2: 核心层迁移 — 框架耦合文件适配
