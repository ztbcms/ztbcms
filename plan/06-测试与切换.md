## 6.3 Makefile 更新

当前 Makefile:
```makefile
serve:
	php -S 127.0.0.1:8081 -t ./tp6/public/
```

**更新为**:
```makefile
# TP6 开发服务器
serve:
	php -S 127.0.0.1:8081 -t ./tp6/public/

# TP8 开发服务器
serve-tp8:
	php -S 127.0.0.1:8082 -t ./tp8/public/

# TP6 清理
clean:
	cd tp6 && rm -rf runtime/*

# TP8 清理
clean-tp8:
	cd tp8 && rm -rf runtime/*

# TP6 Composer install
install:
	cd tp6 && composer install

# TP8 Composer install
install-tp8:
	cd tp8 && composer install
```

## 6.4 文档更新

### 6.4.1 README.md

在 README.md 中说明双版本策略：

```markdown
## 项目结构

- `tp6/` — 基于 ThinkPHP 6 的稳定版本（PHP >= 7.4）
- `tp8/` — 基于 ThinkPHP 8 的新版（PHP >= 8.0）
- `docs/` — TP6 文档
- `docs_tp8/` — TP8 文档（升级指南、Breaking Changes 等）

### 快速开始

#### ThinkPHP 6
```bash
make serve        # 启动开发服务器 http://localhost:8081
```

#### ThinkPHP 8
```bash
make serve-tp8    # 启动开发服务器 http://localhost:8082
```
```

### 6.4.2 docs_tp8/ 目录

TP8 相关文档统一放在 `docs_tp8/` 目录，与现有 `docs/`（TP6 文档）隔离：

```
docs_tp8/
├── README.md           # TP8 版本说明、快速开始、环境要求
├── UpgradeGuide.md     # TP6 → TP8 升级指南（API 变更、配置差异、已移除内容）
├── BreakingChanges.md  # Breaking Changes 清单（ORM、框架 API、配置格式等）
└── ModuleDiff.md       # 各模块适配说明（如有特殊处理）
```

> **原则**: `docs/` 保持 TP6 文档不动，TP8 所有新增/变更文档一律写入 `docs_tp8/`。

## 6.6 上线切换计划

### 6.6.1 切换策略

**推荐: 渐进式切换**

1. **阶段 A — 并行运行**（当前）
   - tp6 和 tp8 同时存在
   - 开发和测试在 tp8 上进行
   - 生产环境继续使用 tp6

2. **阶段 B — tp8 为主**
   - 所有新功能开发在 tp8 上
   - tp6 仅修复 Bug
   - 生产环境可选 tp8

3. **阶段 C — tp6 废弃**
   - tp8 完全稳定后
   - 将 tp8/ 的内容移到项目根目录
   - 保留 tp6/ 作为历史参考
   - 或将 tp6/ 移到 `legacy/tp6/`

### 6.6.2 数据库兼容

- tp6 和 tp8 共用同一个数据库（`ztb_` 前缀）
- 数据库结构无变更（ThinkPHP 升级不影响数据库 schema）
- 如有 migration 文件，需确认 `think-migration` 版本兼容

### 6.6.3 上线检查清单

```bash
# 1. 代码检查
find tp8/app -name "*.php" -exec php -l {} \;

# 2. Composer 依赖检查
cd tp8 && composer validate

# 3. 配置缓存生成
cd tp8 && php think optimize:config

# 4. 路由缓存生成
cd tp8 && php think optimize:route

# 5. 清理运行时
cd tp8 && rm -rf runtime/*

# 6. 部署到测试环境
rsync -avz --exclude='.env' --exclude='runtime/' --exclude='vendor/' \
    tp8/ user@server:/path/to/tp8/
ssh user@server "cd /path/to/tp8 && composer install --no-dev"
```

## 6.7 回滚方案

如果 tp8 上线后出现问题：

1. **Web 服务器回滚**: Nginx/Apache 指回 tp6/public/
2. **数据库**: 无需回滚（共用同一数据库）
3. **代码回滚**: 切回 tp8 之前的 Git commit
4. **缓存清理**: 清除 Redis/File 缓存
