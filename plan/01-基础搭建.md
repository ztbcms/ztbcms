# 阶段 1: 基础搭建 — tp8/ 骨架 + composer 依赖

> **目标**: 在 `tp8` 分支上创建 `tp8/` 目录，安装 ThinkPHP 8 骨架，迁移所有 composer 依赖，确保 `php think` 能正常启动。

---

## 1.1 创建分支

```bash
git checkout develop
git checkout -b tp8
```

---

## 1.2 生成 ThinkPHP 8 项目骨架

```bash
# 在项目根目录执行
composer create-project topthink/think tp8
```

这会生成标准 TP8 骨架：

```
tp8/
├── app/
│   ├── controller/
│   │   └── Index.php        # 默认控制器
│   ├── common.php           # 公共函数
│   ├── middleware.php        # 全局中间件
│   ├── event.php            # 事件定义
│   ├── provider.php         # 容器绑定
│   └── service.php          # 服务注册
├── config/
│   ├── app.php
│   ├── cache.php
│   ├── console.php
│   ├── cookie.php
│   ├── database.php
│   ├── filesystem.php
│   ├── lang.php
│   ├── log.php
│   ├── middleware.php
│   ├── route.php
│   ├── session.php
│   ├── view.php
│   └── ...
├── public/
│   └── index.php            # 入口文件
├── route/
│   └── app.php
├── think                    # CLI 入口
├── composer.json
└── .env.example
```

---

## 1.3 从 tp6/ 复制应用代码

### 1.3.1 复制 app/ 目录

```bash
# 先备份 TP8 默认的 app/ 内容
mv tp8/app tp8/app_skeleton

# 从 tp6 复制
cp -r tp6/app tp8/app
```

> **注意**: 不要覆盖 TP8 特有的 `app/common.php` 和 `app/middleware.php`、`app/event.php`、`app/provider.php`、`app/service.php`，需要合并而非覆盖。具体合并策略见 [02-核心层迁移.md](02-核心层迁移.md)。

### 1.3.2 复制公共资源

```bash
# 静态资源
cp -r tp6/public/static tp8/public/static   # 如果存在
cp -r tp6/public/statics tp8/public/statics

# .htaccess
cp tp6/public/.htaccess tp8/public/
```

### 1.3.3 复制其他目录

```bash
# 数据库迁移文件（如果有）
cp -r tp6/database tp8/database 2>/dev/null || true

# 扩展类库
cp -r tp6/extend tp8/extend 2>/dev/null || true
```

### 1.4.2 依赖变更说明

| 包 | tp6 版本 | tp8 版本 | 变更原因 |
|---|---|---|---|
| `topthink/framework` | `^6.0.0` | `^8.0` | 核心升级 |
| `topthink/think-orm` | `^2.0` | `^3.0`（v3.0.34） | v4.0 与 easywechat PSR 冲突，必须用 v3.0.x |
| `topthink/think-view` | `^1.0` | `^2.0` | TP8 适配版本 |
| `topthink/think-filesystem` | `^2.0` | `^2.0\|^3.0` | 扩展范围 |
| `topthink/think-trace` | `^1.0` | `^2.0` | TP8 适配版本 |
| `symfony/var-dumper` | `^4.2` | **移除** | 改用 `think-dumper` |
| `w7corp/easywechat` | `4.9.0.1` | `4.9.0.1` (fork) | 沿用 Jayin fork，已兼容 PHP 8.3 |
| `intervention/image` | `^2.7` | **已移除** | 已从代码库中移除 |
| `league/flysystem` | `2.5.0.1` | **移除** | 使用 think-filesystem 自带版本 |

### 1.4.3 自定义 VCS 仓库处理

tp6 中有 3 个 fork 仓库：

```json
"repositories": [
    {"type": "vcs", "url": "https://github.com/Jayin/flysystem.git"},
    {"type": "vcs", "url": "https://github.com/Jayin/easywechat.git"},
    {"type": "vcs", "url": "https://github.com/Jayin/socialite.git"}
]
```

**策略**:
- **flysystem fork**: TP8 的 `think-filesystem ^2.0|^3.0` 可能已内置兼容，先不引入 fork，测试后决定
- **easywechat fork**: **直接沿用**，已兼容 PHP 8.3，tp8 composer.json 中保留此 VCS 仓库
- **socialite fork**: easywechat fork 依赖，一并保留

## 1.6 安装依赖并验证

```bash
cd tp8
composer install
php think version
php think
```

**预期结果**:
- `composer install` 无报错
- `php think version` 显示 ThinkPHP 8.x
- `php think` 显示可用命令列表

## 1.8 遇到问题的处理

| 问题 | 解决方案 |
|------|---------|
| `composer install` 报包冲突 | 逐个移除冲突包，记录到 [05-第三方依赖.md](05-第三方依赖.md) |
| `think-multi-app` 无 TP8 版本 | 查看 Packagist 或 GitHub，可能需要 `dev-master` |
| `think-view` 无 TP8 版本 | 查看是否已合并到 framework 核心 |
| PHP 版本不满足 | 使用 `phpbrew` 或 Docker 切换 PHP 版本 |
