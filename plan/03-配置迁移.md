## 3.2 逐文件迁移策略

### 3.2.1 `app.php` — 应用配置 🔴 关键

**tp6 关键配置项**:
```php
return [
    'auto_multi_app' => true,       // 多应用模式
    'app_express'    => true,        // 快速访问
    'default_app'    => 'home',      // 默认应用
    'exception_tmpl' => app()->getAppPath() . 'common/view/tpl_exception.php',
    // ...
];
```

**TP8 适配要点**:
- `auto_multi_app` 配置项需确认 TP8 的 `think-multi-app` 包是否仍使用此 key
- `app_express` 配置项是否仍存在
- `app()->getAppPath()` 调用在配置文件中的可用性（TP8 可能改为 `app_path()`）
- `app_namespace` 在多应用模式下通常为空

**操作**:
```bash
# 以 TP8 骨架的 config/app.php 为基础
cp tp8/app_skeleton/../config/app.php tp8/config/app.php
# 然后合并 tp6 的业务配置项
```

**合并项**:
- `auto_multi_app` / `app_express` / `default_app` — 确认后写入
- `exception_tmpl` — 改用 `app_path()` 助手
- `app_map` / `domain_bind` / `deny_app_list` — 从 tp6 迁移
- `error_message` / `show_error_msg` — 从 tp6 迁移

---

### 3.2.2 `database.php` + `dataconfig.php` — 数据库配置

**tp6 结构**: `database.php` 引入 `dataconfig.php`，后者读取 `.env`。

**TP8 适配要点**:
- 数据库配置结构在 TP8 中基本不变
- `config_path()` 助手在 TP8 中是否仍存在 → 改用 `app_path()` 或直接 `__DIR__`
- `auto_timestamp` / `datetime_format` 等字段名不变
- `schema_cache_path` 中 `app()->getRuntimePath()` 需确认

**操作**:
```bash
cp tp6/config/database.php tp8/config/database.php
cp tp6/config/dataconfig.php tp8/config/dataconfig.php
```

**可能的修改**:
```php
// tp6: $cmsDataConfig = require config_path() . "dataconfig.php";
// tp8: $cmsDataConfig = require __DIR__ . "/dataconfig.php";
// 或者直接合并为一个文件
```

### 3.2.3 `view.php` — 模板引擎配置

**tp6 版本**:
```php
return [
    'type' => 'Think',
    'layout_on' => true,
    'layout_name' => "../../admin/view/element_layout",
    'taglib_pre_load' => 'app\common\taglib\Ztbcms',
    // ... tpl_begin/tpl_end 等
];
```

**TP8 适配要点**:
- `think-view ^2.0` 的配置格式可能有变化
- `type => 'Think'` 是否仍为有效值
- 布局配置 `layout_on` / `layout_name` 是否仍支持
- **`taglib_pre_load` 配置项直接删除**（Ztbcms 标签库已验证为死代码，见 [04-模块迁移.md](04-模块迁移.md)）

**操作**:
```bash
cp tp6/config/view.php tp8/config/view.php
# 然后从 view.php 中删除 'taglib_pre_load' 那一行
```

### 3.2.4 `queue.php` — 队列配置

**tp6 版本**: 支持 sync/database/redis 三种驱动。

**TP8 适配要点**:
- `think-queue ^3.0` 在 TP8 中可能有新版本
- 驱动配置格式是否变更
- `database` 驱动的表名 `queue_jobs` 是否需调整

**操作**: 直接复制，运行队列命令验证。

## 3.3 env() 助手兼容性

TP6 和 TP8 的 `.env` 格式相同（INI style with sections），`env()` 助手函数在 TP8 中仍存在。

**验证步骤**:
```bash
cd tp8
php think env
# 或在 tinker 中测试
php think tinker
>>> env('database.hostname')
```

## 3.4 配置缓存

TP8 新增了配置优化命令：
```bash
php think optimize:config   # V8.1.3 新增
```

迁移完成后建议运行此命令生成配置缓存。
