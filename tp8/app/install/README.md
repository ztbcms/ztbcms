# 系统安装向导

这是 ZTBCMS 框架内置的自动化安装向导模块。主要用于在首次部署系统时，引导用户完成服务器运行环境的校验、基础数据库的初始化构建、初始配置文件的生成以及超管账户的创建。

## 主要功能

- **环境检测**：自动检测 PHP 版本、必要扩展以及涉及配置生成和上传相关的目录读写权限。
- **数据库打底**：提供自动化的 MySQL 链接测试与 SQL 数据结构导入。
- **配置生成**：系统参数配置的可视化输入，并自动注入安全的系统全局环境变量（`.env`）。
- **初始化绑定**：一键完成超级管理员的创建及 `admin`、`common` 等基础架构模块的默认安装启用。

## 服务器环境要求

为确保安装能顺利执行，请在启动安装向导前复核服务器或本地环境配置：

1. **PHP环境**：PHP 版本 `>= 8.2`。
2. **开启的 PHP 函数/扩展**：
   - `session_start`
   - `file_uploads` (允许文件上传)
   - `mb_strlen` (MBString 扩展)
   - `curl_init` (CURL 扩展)
3. **必需的目录读写权限**（进程具有对应路径的读写权限）：
   - `public/`
   - `app/install/`
   - `config/`

## 安装模式一：通过页面向导安装

### 1. 准备阶段
确保您的 Web 服务（如 Nginx 或 Apache）已将 `Document Root` （运行目录）指向到本项目的 `tp8/public/` 目录下，并确保已完成 `composer install` 指令以安装必要的 Vendor 依赖。

### 2. 启动向导
打开浏览器，访问您的站点域名地址。当系统中不存在锁定文件 `install.lock` 时，路由将会自动引导您进入安装向导界面（即访问 `/install` 的模块）。若无自动跳转，可直接访问 `http://<您的域名>/index.php/install/index/index`

### 3. 环境监测 (Step 2)
在安装页面查阅自检报告，向导会列出哪些项目符合要求，哪些目录不可写或函数未开启。如果存在标红的异常项目，请修改服务器配置或目录权限后，点击“刷新”重试。只有环境全部合规，才允许进入下一步。

### 4. 填写配置项 (Step 3 & 4)
按照页面表单提示填写如下关键信息：
- **数据库连接**：输入准备好的 MySQL `主机IP`、`端口`、`数据库用户名`、`密码`以及指定的`数据库名`。您可以自定义数据表前缀。
- **站点基本信**：设定您的网站名称、网站短介绍和相关的 SEO 关键词。
- **超级管理员创建**：输入你想设定的管理员用户名（manager）、密码以及邮箱。

填写完毕后向导会自动利用您提供的信息发起一次数据库连接测试。若是成功，则进入数据部署阶段。

### 5. 执行安装部署
此过程由程序自动运行，主要包括：
1. **执行 SQL**：读取 `app/install/data/cms.sql`，执行建表、初始化表结构。
2. **写入环境变量**：将您填写的数据库配置结合自动生成的复杂加密安全码，根据 `app/install/data/env.example` 模板通过保护区块（`### ZTBCMS_INSTALL_START ###`）注入到项目根目录的 `.env` 环境文件中。同时，站点信息等选项会被写入数据库系统配置表中。
3. **创建账号**：将刚填写的后台登录账户与密码采用加密写入刚初始化的对应数据表中。
4. **安装系统模块**：内在地通过 `ModuleService` 直接拉起安装流程，激活并安装自带的核心系统模块 `admin` 与 `common`。

### 6. 安装完毕 (Step 5)
系统会在应用的根目录路径下（`app_path()` 平级或当前指定层），自动创建一个特殊的锁定文件 `install.lock`。
安装向导每次启动时都会优先查验该文件是否存在，只要该文件存在，便会主动拦截所有的重装请求，保障系统不会被恶意破坏或意外重置。

## 安装模式二：命令行 (CLI) 安装

为提升 Docker、CI/CD 自动化部署体验，系统支持利用控制台命令在服务器终端快速执行安装部署。

### 交互式安装

在项目根目录下键入以下命令即可进入终端问答式的一键安装流程。支持默认选项直接回车跳过：

```bash
cd tp8/
php think ztbcms:install
```

### 静默自动化安装

如果您处于无人值守或全自动流水线中，您可以使用 `--force`（或 `-f`）加上参数完整配置数据库完成秒级应用搭建。未填写的非必填项将继承对应默认值。

```bash
php think ztbcms:install -f \
  --db_host 127.0.0.1 \
  --db_port 3306 \
  --db_name your_db \
  --db_user root \
  --db_pwd root_password \
  --manager admin \
  --manager_pwd admin_password
```

### 仅检测环境 (Pre-flight check)

如果您只想在流水线前置节点确认服务器组件与权限是否满足安装要求而不执行安装任务，可以使用 `--checkEnv` 参数：

```bash
php think ztbcms:install --checkEnv
```

这将会输出当前环境探测结果（`[通过]` 或 `[不通过]`），若全部通过则退出码（Exit Code）为 0，一旦有任何异常则由于环境阻塞返回非零退出码（1）。该命令能够**绕过系统中可能存在的 install.lock 锁定文件直接执行**。

**支持的全量配置参数及默认值：**
* `--db_host` (127.0.0.1)
* `--db_port` (3306)
* `--db_name`  (`必须提供`)
* `--db_user` (root)
* `--db_pwd`   (`必须提供`)
* `--db_prefix` (ztb_)
* `--manager` (admin)
* `--manager_pwd` (`必须提供`)
* `--manager_email` (admin@admin.com)
* `--sitename` (ZTBCMS)
* `--siteurl` (http://localhost)
* `--siteinfo` (全新的管理系统)
* `--sitekeywords` (ztbcms)
* `--force`或`-f` (静默无交互执行安装)
* `--checkEnv` (仅检测依赖环境并退出)

## 常见问题与重装指南

如果您在安装途中意外中断、需要修改底层前缀，或者是需要完全重新安装您的系统，请执行以下重置操作：
1. 手动**删除服务器生成的锁定文件** `install.lock`。
2. 手动清理或删除 `.env` 中由安装向导自动生成的环境变量区块（包含 `### ZTBCMS_INSTALL_START ###` 所在的区域）。
3. 保证目标数据库内的旧表内容已做备份或清空（防止因前缀相同导致的 SQL 执行冲突）。
4. 重新访问域名启动安装重装。
