# ZTBCMS ThinkPHP 8

ZTBCMS 的 ThinkPHP 8 实现，核心框架版本为 ThinkPHP 8.1

## 环境要求

- PHP 8.2 及以上版本
- MySQL 5.6 及以上版本
- Composer 2

## 快速开始

```bash
composer install
cp .env.example .env
php -S 127.0.0.1:8088 -t public public/router.php
```

访问 `http://127.0.0.1:8088/`

完整的安装、迁移、验证和部署说明见 [`docs_tp8`](../docs_tp8/README.md)
